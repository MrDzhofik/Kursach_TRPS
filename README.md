# Туристический навигатор 2.0
Данное приложение будет использоваться для диплома по созданию веб-приложения для путешественников


### Основная цель:
Нахождение оптимизированного пути между несколькими точками методом ближайшего соседа

### Возможные улучшения:
1. Алгоритм поиска пути
2. Алгоритм оптимизации
